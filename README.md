# LAN快传

局域网极速文件互传工具 —— 电脑 ↔ 手机浏览器，扫码即用。

## 特点

- 纯本地局域网互传：不注册、不联网、不传云端，文件不出内网
- 手机扫码即用：微信/QQ/系统浏览器都能用，无需装 App
- 单文件绿色版：免安装、不写注册表、不驻留后台
- 拖拽大文件实时进度 + 全链路异步（并发多设备互不拖累）
- 大文件分片上传 + 断点续传，手机锁屏、切网后接着传
- PIN 码门锁：防同一 Wi-Fi 下他人蹭看
- 在线检查更新：有新版静默提示，程序绝不自行下载替换自身

## 最新版本

**PRO v1.14.0**（2026-11-10）— 手机端上传面板重做 + 三批底层加固 + 深色界面收尾

- **手机端上传**：选照片 / 选视频 / 选文件 / 选文件夹四个独立入口；队列默认全勾可逐个剔除；【＋ 再选一批】保留已选、跨批自动去重
- **防爆盘**：分片缓存跟随共享盘、上传前预检剩余空间、合并改为共享盘内同卷原子改名（不再 C 盘写一遍整包再复制）
- **防假死**：读请求头 / 读请求体 / 下载写回三条异步路径加空闲超时，半开连接不再锁死文件；「发送文件到手机」改后台复制
- **防误伤**：系统时间被改动的正版用户不再被静默锁 24 小时，时间校准即解锁；防破解强度未削弱
- **防吞文件**：`NUL.txt` / `CON.txt` / `com1.log` 等系统保留名在首片即拒收；超长名拦截；中文长名不受影响
- **体验**：单文件下载支持 HTTP Range 断点续传；共享目录根可直接打包；已压缩格式跳过 deflate（打包提速 72%~85%）
- **界面**：桌面端日志表头、下拉框箭头、系统标题栏三处白斑抹平
