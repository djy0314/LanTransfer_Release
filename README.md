# LAN快传

局域网极速文件互传工具 —— 电脑 ↔ 手机，扫码即用；也能把电脑当一台**轻量 NAS**，用 WebDAV / SMB 挂成网络驱动器。

纯本地局域网，不注册、不联网、不传云端，文件不出内网。单个 exe，免安装、不写注册表。

---

## 特点

- **手机扫码即传**：微信 / QQ / 系统浏览器都能用，不用装 App、不用账号、不用数据线
- **把电脑当 NAS**：一键开 **WebDAV** 映射成资源管理器里的盘符，或开 **SMB** 让同事粘一行路径就像本地文件夹一样读写（PRO）
- **大文件不费劲**：5 MB 分片上传 + 断点续传，锁屏 / 断网后只补缺片；下载也支持 `HTTP Range` 续传
- **传完自动归位**：图片 / 文档 / 视频自动分类，按年月或**拍摄时间**归档，同名自动改名 / 覆盖 / 跳过（PRO）
- **网页控制台**：浏览器里看状态、看日志、管文件、软暂停、改归档规则与 PIN（PRO）
- **收作业神器**：文件收集模式一键「只进不出」，下载 / 打包 / 预览 / 列目录 / 直链五大通道全 403
- **纯本地**：不注册、不联网、不传云端，文件不出内网
- **单文件绿色**：免安装、不写注册表、不驻留后台，配置只在 `%APPDATA%\LAN快传\`
- **多网卡选得对**：一块网卡多个 IP / 多网段各占一行，运行中切 IP 自动重绑，已连手机 PIN 不掉线
- **商业级安全**：管理令牌 DPAPI 加密、登出真吊销、PIN 失败锁定、WebDAV 爆破锁定、**真实物理路径闸门**（junction / 符号链接一律拒收）、路径穿越与预览 XSS 防护、共享目录系统与 AppData 黑名单、分片缓存不占系统盘并逐片空间预检、一机一码授权 + 混淆加壳

## 快速开始

1. 下载并解压，双击 `LAN快传_Pro.exe`（免费版同理）
2. 点【启动服务】，界面出现二维码与访问地址
3. 手机连同一个 Wi-Fi，扫码（或浏览器输入地址），输 PIN 即可

> 首次运行 Windows 可能提示「未知发布者」，杀毒软件也可能报「加壳 / 未知程序」——程序没买代码签名证书 + 做了防篡改加壳，属于误判。处理方式与官方 SHA256 校验方法见[官网下载页](https://tools.zf314.cn/)。

## 核心功能

### 传文件

- **手机 → 电脑**：文件、图片、视频、**整个文件夹**（保留目录层级）
- **电脑 → 手机**：按钮选文件或直接**把文件 / 文件夹拖进窗口**，进度实时
- **文字互传**：一段文字直接发到另一台设备，复制即用
- **大文件分片上传 + 断点续传**：5 MB 一片，手机断网、锁屏、切后台后重选同一文件只补缺片；逐片 MD5 校验 + 拼合后三道校验（片序 / 片数 / 总长），坏片直接拒收
- **全链路异步**：多台手机同时传互不拖累，慢设备不拖住快设备

### 手机端上传面板

- **四个独立入口**：选照片 / 选视频 / 选文件 / 选文件夹（点「选照片」直接进相册）
- **队列可逐个剔除**：默认全勾，不想要的点一下剔除（不再是「选了 30 张只能全传」）
- **【＋ 再选一批】**：保留已选继续加，跨批按「相对路径 + 大小 + 修改时间」自动去重
- 顶部实时显示「已选 N / 共 M · 合计 xx MB」

### 浏览与下载

- **在线预览**：图片、音频、视频直接在浏览器播放（Range 流式，不占手机内存）
- **打包下载**：任意目录一键打 zip（共享目录根也能打包）
- **单文件断点续传**（PRO）：`HTTP Range`，206 / 416 规范实现，断网后只补缺失片段
- **极速打包**：jpg / png / mp4 / zip / apk / pdf / docx 等已压缩格式跳过 deflate

### 归档与整理（PRO）

- **自动分类**：图片 / 文档 / 视频 / 其他
- **日期归档**：不分日期 / 按年·月 / 按年·月·日 / 按年-月-日，目录拼接顺序（日期优先 / 分类优先）可切
- **按原始时间归档**：照片视频读 EXIF 拍摄时间与文件时间，2023 年拍的老照片就落进 `2023年\03月`，不按接收时间堆
- **同名冲突策略**：自动改名 / 覆盖 / 跳过，三种都可选，网页端与桌面端一致
- **文件收集模式**：一键「只进不出」，下载 / 打包 / 预览 / 列目录 / 直链五大通道全 403，手输网址也绕不过

### 分享

- **定向提取码**（PRO）：给单个文件生成带令牌的链接，对方不用输 PIN 就能下，链接只管这一个文件
- **访客端 PC 宽屏**（PRO）：大窗口自动两栏（左上传右列表），支持整屏拖拽、整个文件夹拖入

## 当 NAS 用：两种系统级接入（PRO）

### 1) WebDAV 网络驱动器

把共享目录映射成 Windows 资源管理器里的一个盘符，任何支持 WebDAV 的 App（ES 文件浏览器、nPlayer、Documents、群晖客户端等）都能直接读写。

- 入口：桌面端 PRO 设置 → 开启 WebDAV，映射 `http://电脑IP:端口/dav/`
- **一键修复 Windows 限制**：自动设置 `BasicAuthLevel=2` / `FileSizeLimitInBytes=0xffffffff` 并重启 WebClient，写完回读自证
- **匿名只读档**：封 445 端口的环境可用，免密码、只能看不能改
- **固定 PIN 强绑**：随机 / 无 PIN 模式下开关置灰且路由层拒绝
- **爆破锁定**：按来源 IP 连错 5 次锁 30 秒，锁定期间连正确 PIN 也拒

### 2) 系统级共享（SMB）

点一下自动建临时账号并把目录共享出去，同事在资源管理器粘 `\\电脑IP\LANTransfer`、输一次密码就能像本地文件夹一样读写——**同事电脑零注册表、零安装、零设置**。

- 纯系统 API 实现（netapi32 / mpr / SCM / COM，不产生任何子进程），绕开安全软件「命令行添加用户账号」规则
- 账号名固定 `LTShare_` 前缀，共享名与账号名走白名单校验，不合规一个系统调用都不发
- 关闭即删账号，异常退出后重启会自动检测残留并在 PRO 设置里提示一键清理

## 网页控制台（PRO）

浏览器打开 `http://电脑IP:端口/admin`，输管理令牌即用：

- **状态面板**：运行 / 暂停、版本、激活状态、共享目录、文件数、磁盘余量
- **日志**：增量长轮询，出问题直接看现场
- **文件管理**：浏览、预览、改名、删除、上传（根目录拖拽按归档规则落盘）
- **软暂停**：暂停后手机端与 WebDAV 一律 503，管理员通道保留
- **设置**：改固定 PIN（改完立刻吊销全部会话）、改共享目录、改归档规则与冲突策略

**安全设计**：令牌用 Windows DPAPI 加密存 `pro_config.ini`（只有本机当前用户能解开）、接口与页面都不回显令牌、登出即吊销服务端会话、共享目录禁止指向系统目录。

## 安全与隐私

| 项 | 做法 |
|---|---|
| 数据去向 | 纯局域网直连，不经过任何服务器，不联网 |
| 免安装 | 单 exe，配置写在 `%APPDATA%\LAN快传\`，不写注册表、不驻留后台 |
| PIN | 随机 / 固定（解锁后 7 天免输）/ 关闭；失败按 IP 锁定，锁定期间正确 PIN 也拒 |
| 管理令牌 | DPAPI 加密落盘；`/admin/api/state` 只回 `pinSet` 布尔，不回传令牌与 PIN |
| 会话 | cookie 只放随机 session id，登出即从服务端会话表删除（旧 cookie 立刻 401） |
| 共享目录 | 远程接口拒绝 Windows / System32 / Program Files / ProgramData / `.ssh` 等系统敏感目录 |
| 路径穿越 | 全接口二次校验，`..` / 盘符 / ADS / 设备名 / 重解析点全拦 |
| 预览 XSS | 只允许位图与纯文本内联，html / svg / pdf 一律降级为附件下载 |
| 授权 | ECDSA P-256 一机一码，私钥不出作者机器；启动自校验检测改包 |
| 发布物 | ConfuserEx 混淆加壳；每个版本公布 SHA256，官网可核对 |
